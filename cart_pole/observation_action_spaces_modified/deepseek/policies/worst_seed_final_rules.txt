IF cart position (x) > 2 THEN apply force right (2)
ELSE IF cart position (x) < -2 THEN apply force left (1)
ELSE IF pole angle (theta) > 0 AND pole angular velocity (omega) > 0 THEN apply force right (2)
ELSE IF pole angle (theta) < 0 AND pole angular velocity (omega) < 0 THEN apply force left (1)
ELSE IF cart velocity (v) > 10 THEN apply force left (1)
ELSE IF cart velocity (v) < -10 THEN apply force right (2)
ELSE apply force right (2)
